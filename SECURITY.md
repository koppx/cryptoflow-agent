# Security Policy

## Supported versions

This project is currently pre-1.0. Security fixes target the latest `main` branch until versioned releases begin.

## Reporting a vulnerability

Please do not open public issues for vulnerabilities that could expose sensitive packet data, bypass detection in a high-impact way, or enable misuse. Instead, contact the maintainers privately using the security contact configured on the GitHub repository.

When reporting, include:

- affected version or commit;
- a minimal reproduction using synthetic data where possible;
- impact and expected behavior;
- any recommended mitigation.

## Data handling

Packet captures can contain sensitive metadata and sometimes plaintext credentials. Do not upload private captures to public issues, pull requests, or CI logs.
